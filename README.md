# 栖合 · AI 租房委托 MVP

一个 iPhone-first、可安装、可重复模拟的本地 Web App。工作名「栖合」。当前版本不接真实房源或真实模型，先用确定性规则验证产品闭环：

- 租户口述或键入需求，AI 只追问影响匹配的关键缺口。
- 原始描述被整理为硬性条件、偏好和私密协商授权。
- 平台先核验发布角色、出租权、现场信息、费用与时效。
- 双方 AI 交换结构化事实和报价，真人在候选交付前不聊天。
- 最多交付三套差异化候选，并展示优点、缺点、信息来源和协商事件。
- 仅允许房东本人直租和当前承租人个人转租。
- 举报后立即隔离；客观证据确认中介伪装或收费后，实名主体永久封禁。

## 本地运行

```bash
npm start
```

然后打开 <http://127.0.0.1:4173>。

## 自动测试

```bash
npm test
npm run check
```

当前包含 12 个 Node 自动测试、13 个内置产品断言、5 组可交互边界场景和 9 套模拟房源。

## 测试台

点击右上角烧瓶图标，可以：

- 切换完整委托、预算边界、中介伪装、关键信息缺失、零候选五种场景。
- 运行全部产品规则回归。
- 比较「安心账本」「邻里暖光」「效率模式」三种视觉方向。
- 比较紧凑、舒适、宽松三种信息密度。

## 代码结构

- `index.html`：PWA 壳与设计默认值。
- `src/app.mjs`：全部界面、导航和交互状态。
- `src/fixtures.mjs`：租户委托、出租方草稿、模拟房源与测试场景。
- `src/simulation-engine.mjs`：匹配、议价、风控、举报和发布校验规则。
- `tests/simulation-engine.test.mjs`：确定性自动回归。
- `docs/test-matrix.md`：手工体验和验收矩阵。
- `docs/iteration-log.md`：本轮发现并修复的问题。

## 当前边界

这是流程验证 MVP，不是线上租房服务：

- 语音、照片和现场挑战为界面模拟，没有读取设备麦克风或摄像头。
- AI 为确定性规则引擎，没有连接真实大模型。
- 没有账号、数据库、推送、实名核验、地图、支付或合同能力。
- 所有房源、用户和协商记录均为虚构测试数据，请勿录入真实证件或个人隐私。
