# 栖合 · 租房委托 MVP

一个 iPhone-first 的本地 Web App，只服务房东直租与个人转租。

## 现在可以体验什么

- 用自然语言输入区域、预算、入住时间、通勤、合租和设施要求。
- 系统先解析已有信息，只补问缺少的条件。
- 确认委托后，匹配引擎会核验角色、出租权、费用、时效和硬性条件。
- 供需双方在私密授权范围内报价，用户可以查看实际交换的条件。
- 候选卡会按租户需求重新组织信息，并列出缺点、来源和协商记录。
- 举报先隔离房源；客观证据确认冒充个人或收费后，永久封禁实名主体。

## 当前真实程度

- 自由输入会真实改变预算、区域、通勤、入住日期、合租和设施条件，不再只是替换展示文案。
- 文本理解目前是本地规则解析器，不是大模型。
- 匹配、议价、风控与举报处置会真实运行，但使用的是确定性规则。
- 房源、用户和协商事件均为测试数据；房间照片是为原型生成的视觉素材。
- 语音输入会在浏览器支持 Web Speech API 时调用麦克风；不支持时回到键盘输入。
- 还没有账号、数据库、推送、实名核验、地图、支付或合同能力。

## 本地运行

```bash
npm start
```

打开 <http://127.0.0.1:4173>。

## 自动测试

```bash
npm test
npm run check
```

当前有 21 个 Node 测试、13 个产品规则断言、5 组边界场景和 9 套测试房源。

## 测试台

点击右上角烧瓶图标，可以：

- 切换完整委托、预算边界、中介伪装、关键信息缺失、零候选五种场景。
- 运行全部产品规则回归。
- 比较「白」「高对比」「夜间」三种视觉方向。
- 比较紧凑、舒适、宽松三种信息密度。

## 代码结构

- `index.html`：PWA 壳与设计默认值。
- `src/app.mjs`：界面、导航和交互状态。
- `src/demand-parser.mjs`：自然语言需求解析与缺口识别。
- `src/simulation-engine.mjs`：匹配、议价、风控、举报和发布规则。
- `src/fixtures.mjs`：委托、房源和边界场景测试数据。
- `src/styles-v2.css`：V3 视觉系统。
- `tests/`：解析器与业务规则自动回归。
- `docs/product-facts.md`：参考产品与开源 UI 的核验记录。
- `docs/test-matrix.md`：手工验收矩阵。

请勿在当前版本录入真实证件或个人隐私。
