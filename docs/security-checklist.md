# 住哪儿安全与隐私检查清单

本清单是受控 alpha 的最低门槛。任何标为“阻断”的项目未通过，都不能接收外部试点用户。

## 1. 凭证与配置

- [ ] 阻断：仓库、提交历史、README、截图、测试报告和控制台输出不包含 API Key、联系人密钥、Cookie 或真实联系人。
- [ ] 阻断：real 模式缺少合法 `CONTACT_ENCRYPTION_KEY` 时服务拒绝启动。
- [ ] `.env.local`、`data/`、上传目录和评测结果均在 Git 忽略范围。
- [ ] 文档只引用环境变量名，不记录实际 Key 值或个人 Key 文件路径。
- [ ] Qwen Key 只进入服务端模型客户端，不进入浏览器 bundle、任务 payload 或事件。

## 2. 会话、所有权与越权

- [ ] 阻断：会话 secret 只存在于 HttpOnly、SameSite Cookie；数据库只保存哈希。
- [ ] 阻断：任务、材料、案例、联系人、通知、举报、看房和媒体读取都校验当前 owner 或明确双边关系。
- [ ] 第三方读取真实案例与联系人返回 404，不暴露资源是否存在。
- [ ] 会话撤销与过期后旧 Cookie 立即得到 `SESSION_INVALID`。
- [ ] 浏览器修改请求执行同源检查；不接受跨站 Cookie 写操作。

## 3. 双边条款与联系人门禁

- [ ] 阻断：单方确认后双方联系人仍为 `CONTACT_LOCKED`。
- [ ] 阻断：双方只可确认当前同一 version/hash，过期值返回 409。
- [ ] 阻断：授权绑定案例、条款哈希、双方输入版本、双方 owner 和有效期。
- [ ] 阻断：任务暂停、关闭、过期、输入变化、案例失效、拒绝或 grant 到期都会立即撤销。
- [ ] 当前用户只能读取对手方联系人，不能读取自己或其他案例联系人。
- [ ] 联系人使用 AES-256-GCM、随机 nonce；列表和设置接口只返回掩码。
- [ ] 联系人原值不进入事件、通知、异常、分享文本、history state 或 localStorage。

## 4. AI 数据边界

- [ ] 阻断：Qwen 输入不包含联系人、Cookie、精确地址、材料路径、预算上限或最低授权价，除非该阶段的最小业务契约明确需要且经过脱敏。
- [ ] 模型输出必须经过 schema、allowlist 和确定性策略闸门。
- [ ] 模型不能覆盖用户已确认字段或规则从原话识别出的硬事实。
- [ ] 模型超时、429、坏 JSON 或异常时最多进行受控重试，随后明确降级。
- [ ] Provider 原始错误正文不返回浏览器、不写公开事件。

## 5. 媒体与材料

- [ ] 阻断：身份、角色、出租权和现场核验材料不通过静态目录公开。
- [ ] 阻断：客户端自报“已核验”无效；只有服务端持久审核记录可形成验证事实。
- [ ] 公开房源图需要单独明确同意，且与私密核验材料使用不同记录和路径。
- [ ] 文件经过真实解码、MIME 核对、字节、像素、动画页数和尺寸限制。
- [ ] derivative 经过旋转、限边和 WebP 重编码，不保留 EXIF、GPS、XMP 或 IPTC。
- [ ] 用户文件名不参与服务端路径；候选只返回受控媒体 ID 与尺寸。
- [ ] 删除任务后媒体立即不可读，并进入可重试清理队列。

## 6. 数据最小化与公开投影

- [ ] 阻断：租客候选不含目标预算、最高预算和原话；出租候选不含底价、精确地址和材料引用。
- [ ] 匹配案例与通知 payload 使用固定 schema，未知字段拒绝写入。
- [ ] 产品事件边界递归拒绝私密字段名；指标脚本只输出聚合值。
- [ ] 演示 fixture 带明确标识，永不创建真实案例、确认或联系人授权。
- [ ] README 截图只使用 demo mode 和测试数据。

## 7. 持久化、备份与删除

- [ ] 数据目录权限为 `0700`，SQLite、WAL、SHM 和备份不对其他本机用户开放。
- [ ] 数据库迁移连续、原子，并在升级已有库前生成同目录受限备份。
- [ ] 备份包含与主库同等级的访问控制和保留期限。
- [ ] 删除任务后关联公开媒体不可读；试点结束按运行手册销毁数据库、备份和上传文件。
- [ ] 事故副本只读、访问受限，不通过邮件或聊天工具传输。

## 8. 可靠性与滥用防护

- [ ] 任务创建与 outbox 事件同事务，重复 `clientRequestId` 不产生重复任务。
- [ ] Worker 领取有租约、退避、最大尝试次数、终态告警和幂等 job key。
- [ ] 处理中的旧版本结果不会覆盖新任务输入。
- [ ] 会话、普通写入、AI 调用和全局预算有独立限流。
- [ ] 请求体、文本、数组、嵌套、媒体和字段长度均有限制。
- [ ] 健康接口在存在终态 worker 失败时返回 degraded/503。

## 9. 前端安全与可访问性

- [ ] 阻断：用户标题、原话、候选内容和错误文本在 HTML sink 前编码；恶意标题测试不执行脚本。
- [ ] CSP、安全响应头和 frame 限制在静态页面启用。
- [ ] service worker 不缓存任何 `/api/` 响应。
- [ ] 离线时联系人从内存清除，页面持续显示连接失败，不保留假成功状态。
- [ ] 弹层具有 dialog 语义、焦点限制、Esc 关闭和焦点恢复。
- [ ] 320、375、430 px 无横向阻断，减少动态效果生效。
