# V3 UI reference facts

> Verified: 2026-08-23
> Purpose: visual research only. No reference assets are shipped in the product.

## 呈迹

- Status: shipping iPhone app on the China App Store.
- Product focus: personal achievement collection, discovery, and progress records.
- Verified interface traits: bold illustrated cards, high-contrast Chinese display type, colored page fields, and optional text animation / haptic settings.
- Source: https://apps.apple.com/cn/app/%E5%91%88%E8%BF%B9-%E6%88%90%E5%B0%B1%E8%AE%B0%E5%BD%95-%E6%94%B6%E9%9B%86%E4%BA%BA%E7%94%9F%E7%9A%84%E4%BB%AA%E5%BC%8F%E6%84%9F%E6%97%B6%E5%88%BB/id6745219866

## 印所

- Status: shipping iPhone app on the China App Store.
- Product focus: turning photos into paper / print-style images.
- Verified interface traits: ink-on-paper identity, strong typographic posters, large negative space, and a single clear action per screen.
- Source: https://apps.apple.com/cn/app/%E5%8D%B0%E6%89%80-ai%E7%85%A7%E7%89%87%E7%94%9F%E6%88%90%E4%B8%8E%E7%9B%B8%E7%BA%B8%E9%A3%8E%E6%A0%BC/id6767815016

## Elys

- Status: shipping iPhone app on the China App Store.
- Product focus: an AI-assisted social product where a user's agent can act before human takeover.
- Verified interface traits: near-monochrome chrome, large dark typography, translucent native-style navigation, and activity shown inside the product surface.
- Source: https://apps.apple.com/cn/app/elys/id6754834695

## IceCubesApp

- Status: active open-source SwiftUI Mastodon client for iOS, iPadOS, macOS, and visionOS.
- Useful implementation reference: native navigation, composable SwiftUI surfaces, configurable themes, accessibility-minded controls, and real production-scale screen states.
- License: AGPL-3.0; no source code or assets are copied into this prototype.
- Source: https://github.com/Dimillian/IceCubesApp

## Original direction for 栖合

- Keep the product's identity original: pure white fields, near-black type, and color reserved for errors or reports.
- Borrow principles, not layouts: tactile hierarchy from 呈迹, restraint from 印所, visible agent activity from Elys, and native interaction discipline from IceCubesApp.
- Remove explanatory copy. Show parsing, filtering, verification, and negotiation as changing product states.
